Verify a draw certificate

Paste a certificate produced by LucentDraw. This page recomputes the commitment, fetches the beacons again on its own, checks drand's signature, and recomputes the order.

    The rule, so you can check without this page

    Everything is SHA-256 over UTF-8 text. C is the hash of the sealed record as canonical JSON (keys sorted, no spaces). The Ethereum value is the hash of the first block whose timestamp is after notBefore, with one confirmation. The seed hashes the label, C, that block hash and the drand randomness, one per line, lowercase hex without 0x, with - for an unused source. Each participant gets the key H("LucentDraw/1\nkey\n" + seed + "\n" + name), and the order is ascending by key.

    The same check in a few lines of Python:

    import hashlib, json
H = lambda s: hashlib.sha256(s.encode()).hexdigest()
rec  = json.load(open("draw-certificate.json"))
spec = rec["spec"]
C    = H(json.dumps(spec, sort_keys=True, separators=(",", ":"), ensure_ascii=False))
ra   = rec["randomness"].get("eth", {}).get("hash", "-")         # check on any Ethereum node
dr   = rec["randomness"].get("drand",  {}).get("randomness", "-") # check at api.drand.sh
seed = H("LucentDraw/1\nseed\n" + C + "\n" + ra + "\n" + dr)
order = sorted(spec["candidates"], key=lambda n: H("LucentDraw/1\nkey\n" + seed + "\n" + n))
print(C == rec["commitment"], order == rec["order"])

    What a pass means

    The order follows from the sealed list and from two public random values, and nobody could choose those values after seeing the list.

    One thing this page cannot check for you: that the commitment was really shared before the target round and block. Look where it was posted, and compare the time.

    The drand value is checked against the quicknet public key with a BLS signature check. For Ethereum, the page checks that the block is the first one after the seal and still on the canonical chain, using your endpoints; for full independence, use your own node.
